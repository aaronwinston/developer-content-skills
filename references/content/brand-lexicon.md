## Never use

| Term | Why | Say this instead |
|---|---|---|
| Unlock / empower / leverage / supercharge | Hype | Describe the action |
| Revolutionary / game-changing | Vendor-speak | Specific, measurable outcomes |
| AI-powered / next-generation / cutting-edge | Hollow modifiers | Drop them |
| Solution / solutions | Generic enterprise-speak | Platform, product, tool, system |
| Excited / thrilled / proud to announce | Performative PR | Lead with the thing itself |
