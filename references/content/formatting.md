# Formatting conventions

> Example house style. Replace product-name rules with your brand glossary.

## Capitalization

- Sentence case for titles and headings. Not Title Case.
- Product names are proper nouns: Arize AX, Phoenix, Alyx, ADB.
- "Arize" alone is acceptable and often preferable; "Arize AI" is the full legal name and should appear in boilerplate, press releases, and legal contexts.

## Punctuation and syntax

- Oxford comma.
- Avoid em dashes where you can.
- Numerals for numbers above nine; spell out one through nine except in headlines and metric callouts.

## Technical formatting

- Use inline code formatting for function names, status values, file names, and CLI commands.
- Use code blocks, not screenshots, for anything the reader might copy-paste.
- Diagrams should illustrate a concept, not decorate the page. Caption them.

## Hyperlinks

- Link the phrase that tells the reader what they will get, not "click here" or "learn more."
- External links to sources like papers, GitHub repos, and customer docs are expected in technical posts. They build credibility.
